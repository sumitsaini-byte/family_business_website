CHAPTER 1: INTRODUCTION

1.1 Background

In today’s digital era, the event services industry is rapidly evolving, with customers increasingly seeking convenient, online solutions for their needs. Family-owned businesses, such as Sadguru Tent House-which is owned by the father of one of our team members-have traditionally operated through offline channels like word-of-mouth, phone calls, and in-person visits. While these methods have served well in the past, they often limit the business’s reach, create inefficiencies in managing bookings and inventory, and make it challenging to deliver a seamless customer experience.

As customers now expect to browse products, check availability, and make bookings online at any time, it has become crucial for businesses to establish a strong online presence. Modern rental platforms offer features such as detailed product galleries, real-time booking systems, inventory management, and secure payment options, all of which streamline operations and enhance user satisfaction.

Recognizing these industry trends and the specific challenges faced by Sadguru Tent House, our team decided to develop a professional online platform tailored to the needs of this family business. By digitizing key processes such as product selection, user registration, booking, and order tracking, the new system aims to reduce manual workload, minimize errors like double-booking, and provide a more organized approach to inventory and customer management.

This project is not only an academic exercise, but also a meaningful opportunity to support a local, family-run enterprise in adapting to digital transformation. By creating a user-friendly and efficient online furniture rental platform, we hope to help Sadguru Tent House expand its digital reach, improve customer service, and position itself for continued growth in an increasingly competitive market.

The primary objective of this project is to design and develop a professional online platform for Sadguru Tent House, a family-owned business specializing in event furniture rentals and owned by the father of one of our team members. 2.4 System Architecture Overview

The system follows a classic three-tier web architecture:

Presentation Layer (Frontend): Built with HTML, CSS, JavaScript, and Bootstrap, providing all user-facing pages and forms.

Application Layer (Backend): PHP scripts process user requests, handle business logic, and communicate with the database.

Data Layer (Database): MySQL stores all persistent data, including user details, products, and bookings.

This architecture ensures maintainability, scalability, and a clear separation of concerns, supporting both customer and administrative functionalities.

CHAPTER 5: IMPLEMENTATION AND TESTING

5.1 Implementation Approaches

The implementation of the Sadguru Tent House furniture rental website followed an incremental development approach, which allowed for progressive building and testing of features. Key implementation strategies included:

Model-View-Controller (MVC) Pattern: Separating business logic, data, and presentation to ensure code maintainability and clarity.

Progressive Enhancement: Building core functionality first, then enhancing with additional features like image galleries and review systems.

Responsive Design Implementation: Using the Bootstrap framework to ensure a mobile-first design that works across all devices.

Database-Driven Content: Creating dynamic pages that pull content from the Mysql database rather than static HTML pages.

User-Centric Development: Prioritising user flows for furniture browsing, booking, and order management based on customer needs.

5.2 Coding Details and Code Efficiency

The implementation uses PHP for server-side scripting with a MySQL database. Key coding details include:

Modular Development: Separate PHP scripts for user authentication, product management, and booking systems.

Database Interactions: Using prepared statements with PDO for all database operations to prevent SQL injection.

Session Management: Secure user sessions with appropriate timeout settings.

5.2.1 Code Efficiency

Several techniques were implemented to ensure code efficiency:

Minification: CSS and JavaScript files were minified to reduce file size and improve load times.

Image Optimisation: All product images were compressed and stored with appropriate formats (JPG).

Database Indexing: Key fields like product_id, user_id, and search-related columns were indexed to improve query performance.

Caching: Implementation of browser caching for static assets to reduce server load.

Lazy Loading: Product images are loaded only when scrolled into view, improving initial page load speed.

Single-Location Support: The system is designed for a single business location and does not support multi-branch management.

Manual Review Moderation: Customer reviews require manual approval by the admin, which may delay feedback display.

User Interface: While responsive, the UI could be further improved for accessibility and modern design standards.

php

<?php

$stmt = $pdo->prepare("SELECT quantity FROM products WHERE id = ?");

$stmt->execute([$product_id]);

$product = $stmt->fetch();

if ($product && $product['quantity'] >= $requested_qty) {

$pdo->beginTransaction();

$stmt = $pdo->prepare("INSERT INTO booking_order (user_id, product_id, quantity_p, rent_in, rent_out) VALUES (?, ?, ?, ?, ?)");

$stmt->execute([$user_id, $product_id, $requested_qty, $rent_in, $rent_out]);

$stmt = $pdo->prepare("UPDATE products SET quantity = quantity - ? WHERE id = ?");

$stmt->execute([$requested_qty, $product_id]);

$pdo->commit();

}

?>
